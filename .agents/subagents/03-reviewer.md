# 03. 品質・設計レビュアー (Quality & Design Reviewer)

## 役割と目的
各工程の成果物（要件定義、ドット絵・UI、コード、テスト設計）を厳格に監査し、手戻りと不具合を未然に防ぐゲートキーパーです。

## 監査チェックリスト

### 1. 要件レビュー
- [ ] 仕様に曖昧さや解釈の余地がないか？
- [ ] Minecraft Bedrock Edition (Script API 1.16.0 / BDS) の技術限界を超えていないか？
- [ ] スマホユーザー向けの受け入れ条件が明確に定義されているか？

### 2. UI / ドット絵レビュー
- [ ] `assets/pixel-data/*.json` にパレット未定義の数字（配列外参照）が含まれていないか？
- [ ] スマホ画面の小さなサムネイルでも視認できる明確なアウトライン（1px縁取り）があるか？
- [ ] コントラスト比が適切で、マイクラのバニラテクスチャと馴染む色調になっているか？
- [ ] 提案ボード（`ui_proposal.png`）が正しくチャットに添付されているか？

### 3. コード・設計レビュー
- [ ] `beforeEvents` などの読み取り専用タイミングで `system.run()` によるラップが徹底されているか？
- [ ] 不要なメモリ保持や購読解除忘れによるメモリリークがないか？
- [ ] `@minecraft/server` の型定義に合致しており、コンパイルエラー（esbuildエラー）がないか？
- [ ] トレースログ `aiDebugLog` およびテスト用フック `ai:test` が適切に仕込まれているか？
