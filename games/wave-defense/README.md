# モンスター襲撃防衛戦アドオン (Monster Wave Defense)

一定周期ごとのWaveでモンスターが襲撃してくるのをマルチ・ソロで協力して撃退するサバイバル防衛ミニゲームです。

## 主な機能
- **難易度3段階**: Easy (5体〜) / Normal (12体〜) / Hard (25体〜)
- **周期Wave進行**: 準備時間カウントダウン、円形包囲スポーン、残存敵数のリアルタイムHUD表示
- **報酬＆経済**: Waveクリア時に全プレイヤーへ「防衛コイン (Wave Token)」を支給
- **クラフト＆強化**: スマホ対応GUIショップ（ActionFormData）から武器購入＆手持ち武器のLv.1〜Lv.5強化
  - 烈火の剣: 火炎継続ダメージ
  - 雷霆の刃: 放電衝撃波で周囲をまとめて感電
  - 氷皇の剣: 敵を氷結させて大幅鈍足付与

## ディレクトリ構成
- `src/` : ゲームロジック（TypeScript / Script API 1.16.0）
- `assets/pixel-data/` : 武器・通貨の数値マトリクスドット絵定義
- `textures/items/` : エクスポートされたテクスチャPNG
- `structures/` : GameTest用構造体
- `manifest.json` : アドオンマニフェスト
